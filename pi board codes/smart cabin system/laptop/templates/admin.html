Connect a cabin device

  1. Put the Pi in the cabin, on the same Wi-Fi / hotspot as this laptop, and run sudo python3 main.py on it.
  2. On the Cabins tab press Add a new device. The Pi appears with a 4-digit PIN.
  3. Check the PIN is the same as on the Pi's own page (http://<pi>:8000) or in its terminal, pick the cabin and press Connect.
  4. The faculty member then logs in on the Pi's page to link their card, register their face and pair their phone.

If the Pi doesn't appear (another network, or broadcasts blocked): press New code next to the cabin and type that 6-digit code on the Pi's page, or run sudo python3 main.py --connect 123456 on the Pi.

Connecting a new device to a cabin replaces its old one (the old token stops working).
